# 🏡 Housing Price Prediction using Simple & Multiple Linear Regression
This project analyzes housing data collected from Redfin and uses Simple Linear Regression and Multiple Linear Regression to predict home prices based on several key property features. The entire analysis is performed in a Jupyter Notebook using Python and Scikit-Learn.

## 📘 Project Overview
The goal of this project is to understand how different factors influence home prices and to build predictive regression models. The dataset includes:

- Home size

- School area

- Built year

- Selling year

- Listed price

This project performs:

- Data preprocessing and exploration

- Correlation analysis

- Simple linear regression (one feature → price)

- Multiple linear regression (all features → price)

- Predictive modeling

- Data visualization with scatter plots and regression lines

## 🧠 Regression Models Used

### ✔️ Simple Linear Regression
Price is predicted using one independent variable at a time, including:

House size

School area

Built year

Each model shows:

Scatter plot of the data

Regression line

Correlation coefficient

### ✔️ Multiple Linear Regression
A combined model that uses all features together to predict home price more accurately. This model captures the interactions between features and typically produces a higher predictive performance.

## 📊 Visualizations
The notebook produces:

Scatter plots for each feature vs. home price

Best-fit regression lines

Correlation heatmaps or coefficient outputs

Prediction results for simple and multiple regression

These visualizations help illustrate the relationships and trends within the data.
